# 🐦 Flappy Bird - Arcade Edition

A browser web game inspired by the classic **Flappy Bird**, built with HTML5 Canvas, modern CSS3, and native Web Audio API sound synthesis.

---

## 🚀 How to Play

1. **Option 1**: Double-click `start_game.bat` or `index.html` directly in this folder (`E:\YT gaming clips\Google\`).
2. **Option 2**: Open `index.html` in Google Chrome, Edge, Brave, or Firefox.

No local web server, node, or python dependencies are required! It works completely offline and standalone.

---

## 🎮 Controls

| Action | Control |
|---|---|
| **Flap / Fly / Start** | `Spacebar` / `Up Arrow` / `Left Mouse Click` / `Touch screen` |
| **Pause / Resume** | `P` key or the top-right `⏸️` button |
| **Mute / Unmute** | `M` key or the top-left `🔊` button |
